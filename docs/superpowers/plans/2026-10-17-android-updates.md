# 安卓应用内更新

目标：首次安装 3.3.0 后，打开应用可收到新版提醒，并从设置手动检查更新。无后台常驻推送，不静默安装。

架构：Pages 托管公开版本清单，GitHub Release 托管 APK。独立更新客户端不携带运营账号凭据；校验 HTTPS 来源、大小、SHA256、包名、递增版本和安装签名。FileProvider 仅开放 updates 缓存目录。

- [ ] 先写 UpdatePolicy JVM 测试并观察失败，再实现清单解析、下载限制与校验。
- [ ] 独立 UpdateController：检查、下载进度、权限引导和系统安装；界面销毁取消工作，失败不影响写卡。
- [ ] 接入启动/设置和三语言文案；写卡、未同步结果存在时不允许进入更新流程。
- [ ] 增加清单发布脚本与中文说明；发布 APK 后再发布对应摘要清单。
- [ ] Android 单测、构建、lint、签名校验、独立代码审查；实体手机安装验收仍由负责人完成。

边界：保持应用数据，不卸载旧版；旧版不具备检查能力，需要最后一次手动安装。Android 要求用户授权此应用安装来源并确认安装。离线或清单故障不阻止现有写卡。
