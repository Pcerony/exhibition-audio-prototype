## 当前开发重点

基础功能阶段已获用户阶段性确认，真实运营账号已可登录，用户反馈录音及各工具正常。当前进入体验优化准备：参观者网页、运营管理后台、管理人员 Android 应用。详细设备矩阵和正式展览准备事项独立保留，见进度与验证记录。

旧的 `docs/superpowers/specs/2026-09-29-exhibition-audio-nfc-design.md` 和早期原型计划记录了单浏览器原型阶段的决定；如与本文档冲突，以本目录核心文档为准。
