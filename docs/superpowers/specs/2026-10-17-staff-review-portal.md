# 现场工作人员网站

按用户已经明确的要求直接实施，不再要求非技术用户确认实现选型。

- 新入口 `#/staff`，手机优先，保留最高权限后台和 Android 写卡端。
- 现场端提供中文、日文、英文语言切换；列表顶部只显示语言控制和当前成员/账号操作，不重复显示产品或研究室标题。
- 一个共享 Supabase Auth 工作人员账号，服务端独立 `staff` 角色；管理员账号也能进入，不能向工作人员分发管理员凭据。
- 首次登录后选择成员，浏览器记住会话和成员。名单取自 https://www.sodes.org/ja/members.html （2026-10-17），排除張彦芳和 Zoé Láscari，其余八人。可切换成员或退出。不保存密码；成员是共享账号下的自报身份。
- 列表默认全部卡片，录音提交时间倒序、空卡最后，明确显示日本时间到秒。直接显示草稿/已修改的转写正文，以正文、卡号检索；支持待审核/已发布/空卡、四个固定回忆主题和日期筛选、分页。待修正与公开卡片用不同底色区分，文字状态仅保留给辅助技术读取。
- 单条审核：短期签名音频试听、编辑文字、保存待审核、确认并发布。未发布文字永不进入访客页面；修改已发布文本并保存待审核会暂时隐藏文字，不影响音频。
- 复用已有 73 块板轮廓、地点转换和地图组件，显示板号、系统推算/手工修正来源、需核对/图外/未选点；Google 地图按既有地点打开。已有 pin 可显示板内点；Places 坐标只在当前地图查看内存使用，不新增持久坐标。
- 工作人员不能开卡、写卡、重置、删除、启停、批量管理、导出或修改地图归属。服务端拒绝这些动作，而非只隐藏按钮。
- 每次保存、审核、音频打开、地点查看记录认证账号、所选成员快照、卡片/录音、动作和服务端时间；不记录音频、转写正文、token 或签名网址。每条卡片可查看操作历史，列表显示最近审核人和时间。
- 多人使用通过转写 version 防止相互覆盖。保存冲突保留本地文字，要求重新载入；不静默覆盖。每 20 秒/返回前台更新列表，编辑框不被后台刷新清空。
- 后端使用独立 `staff-api` 和仅 service-role 可执行的 `staff_action`；专用分页 DTO 可返回私有草稿正文，既有 admin list/CSV/匿名契约不扩散正文。
- 不改动生产数据、账号、DNS或部署配置。候选需前端、后端、迁移和响应式验证后交付；共享账号开通与生产发布另行执行。
