# 安全与隐私

## 现场工作人员端

- 一个共享认证账号，`staff` 角色不能调用完整 `admin-api`。成员名单不是 Auth 账号；自选署名便于现场协作，但不是独立身份认证，不保证不可冒名。
- 专用认证列表可读私有转写正文；原有后台列表/CSV仍不携带正文。浏览器会话使用独立存储键，不保存密码；成员选择按后端和账号隔离。跨标签页账号变化会清空列表和编辑器，请求前后均校验账号一致。
- 每次保存以版本校验和数据库锁保护；AI完成也递增版本。冲突保留本地编辑，不自动覆盖他人审核。人工保存撤销旧AI租约。只有同意转写的有效录音可审核，公开端仍只读已批准正文。
- 审计使用服务端时间、认证账号UID和服务端成员名称快照，记录试听申请、地点查看、保存和批准，不记录正文、音频、token或签名URL。音频经授权签发120秒链接，不返回对象路径。
- 手机记住登录意味着持有该手机会话的人可使用共享权限；遗失设备时应撤销会话，展期结束应停用账号。详细开通说明见[工作人员接入](STAFF_PORTAL_SETUP.md)。

## 可选 AI 转写

只处理参观者主动勾选同意的新录音，旧录音默认不同意。Groq 密钥仅放 Edge Function Secrets；服务器下载私有音频后上传至固定转写接口，不向外部提供存储签名链接。草稿不进入公开列表或匿名表查询；文字必须经认证工作人员确认发布后才在当前有效绑定的收听页出现。文本以纯文本渲染，禁止执行 HTML。重置/删除级联取消任务，人工修改和重试撤销旧租约。默认不自动公开、不翻译、不概括。详见[试用接入](TRANSCRIPTION_SETUP_ZH.md)。

## 音频告知与数据最小化

- 提交前用简体中文/日文清楚告知：录音会绑定到这枚公开展签，之后扫描该展签的人都能收听；不要录制不愿公开的内容。
- 昵称可选，长度受限；不收集姓名、邮箱、电话或设备实时定位。回忆地点由访客主动选择且可跳过，不要求家庭住址；提交前告知地点会随录音公开。
- 录音仅在用户主动点击开始后访问麦克风；上传需要用户点击提交。
- 展览运营方须确定隐私联系人、保存期限、展期结束后的删除策略和用户请求处理方式。未确认保留期限前不得将试录当作正式数据长期保存。

## 访问控制

- 二维码备用页面复用现有工作人员登录（`#/staff/qr`）或运营后台登录（`#/admin/qr`），不增加账号或角色模型。工作人员页面的界面只有二维码创建流程；服务端沿用staff-api认证会话，以原子事务幂等创建不透明访客token身份并写`qr_issue`审计，不产生写卡任务。二维码公开网址仍只允许原有访客查询/录音/播放能力。
- 规划中的[QR补卡](QR_NFC_WORKFLOW.md)沿用Android运营认证，不新增角色或通过公开URL授予写卡权限。补写须保持原身份/录音，以专用任务、版本、租约和完整URL读回保护；不确定物理结果不能自动配另一枚卡。补卡审计不含完整token/URL、音频正文或租约秘密。此能力未实现，不能用普通写卡接口绕过QR隔离。

- `service_role`、数据库密码、加密密钥仅保存在 Supabase/GitHub Actions secrets 或受控 server 环境；不得进入 Vite `VITE_*` 环境变量、浏览器 bundle、Android APK、CSV 或日志。
- 所有 exposed Postgres 表启用 RLS；除明确需要的调用路径外撤销 anon/authenticated 直接写入权限。Storage 默认 private，并用最小权限策略。
- 访客 token 作为公开查找 handle，不是运营凭据；持 token 最多查询该标签和申请这条音频的上传/播放。不能列表、覆盖、重置、改昵称或读其他标签。
- Android app 与 admin 共享运营者认证；本轮扩展经认证的卡片查询、试听、移动/重置/删除，不开放匿名管理。写卡另有任务租约和协议版本保护；不可把service-role key打包进APK。
- Android 2.1.1允许运营者在单张写卡中显式确认覆盖已有NDEF内容；许可仅绑定当前任务与租约的一次触碰，切后台/页面/账号后失效，自动模式不继承。只能替换可写且容量足够的芯片，仍需服务端授权和物理读回，不自动删除原卡片或云端录音。访客无覆盖权限。
- Android记住登录只保存Keystore加密会话，不保存明文密码。会话续期后仍须确认运营角色；退出/撤销后停止NFC，清除本机会话，不将不同账号的待同步报告混用。
- 批量删除/重置/移动按预检版本执行，录音状态发生变化须重新确认，不能把刚绑定录音的卡按空卡删除。逻辑删除不等于立即物理清除私有对象，回收仍受上传签名有效期约束。
- 重置/停用/启用/重写标签要经过确认并写入 operator ID、动作、目标和时间审计，不写录音内容或秘密 token 到审计日志。

## 音频对象

- 私有 bucket、随机不可预测的对象 key、无 upsert；数据库记录 `object_path` 而不是公开 URL。
- 上传签名限定单个对象和有限时长；服务器验证对象真实 MIME/大小，不只信任浏览器声明。初版录音 UI 上限为 60 秒；正式 `MAX_AUDIO_BYTES` 和 MIME allowlist 以配置及真机格式测试定稿。
- 播放每次由服务端签发短时 URL；任何 signed URL 在有效期内都可播放，因此时长须短并在重置后避免延长签名。
- upload finalize 不成功的对象不可公开播放；清理任务回收过期候选/失败并发对象。重置需避免留下可长期访问的孤儿文件。

## 滥用与可靠性

- 访客上传初始化和 finalize 限速；限制单 token 上传次数、对象字节、时长和允许 MIME；为 API 错误返回 request ID。
- 数据库原子 claim/唯一约束是防覆盖的权威，不依赖前端“先查未绑定”或按钮禁用。
- 移除或更改录音必须运营认证。匿名 API 对重复提交返回已有录音状态，不泄漏其他标签列表。
- 日志只保留故障排查所需的最少元数据；禁止记录原始音频、麦克风流、签名 URL、完整访客 token 或请求 authorization。
- 数据备份、恢复演练、删除同步和展览结束清理需纳入上线清单。
