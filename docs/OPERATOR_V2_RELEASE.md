## 发布前

- 保存数据库schema及与迁移相关表的受控备份，备份不得提交仓库或包含在公开产物中；确认能够恢复。
- 只读查看旧batch到分类的分组数量及空名称数量；确认不会重建token或覆盖原标签，旧label作为历史管理标识保留。
- 分类/号历史/软删除/任务租约migration从空库及旧库夹具重放；跑授权、预检竞态、并发号分配/任务占用测试。
- 网页两种构建与桌面/手机截图，Android三语、会话续期、退出和后台停止写卡测试；完整安装包不含服务端秘密。
- 发布操作串行执行，子任务不得直接改变生产资源。没有数据库备份或无法连接授权管理API时，只交付本地版本，不冒险改生产。

## 升级顺序

1. 向工作人员提供V2 APK与升级说明，暂停正在进行的写卡活动，确保待同步结果处理完。
2. 执行migration dry-run，确认仅包含本轮新迁移；应用schema与Edge服务端扩展。
3. 用虚构独立测试分类/卡验证新增、移动、删除分组、访客录音播放以及V2租约。
4. 部署网页后台并核对生产配置；旧APK明确显示需要升级，不能继续旧协议写卡。
5. 用实体芯片检查单张模式与自动模式，确保同一芯片未移开不推进编号；记录设备/OS/芯片型号。

## 回退与故障

不能仅回滚网页bundle或安装旧APK后继续写卡：旧协议已受保护。先暂停V2写卡，保存错误日志中不含秘密的错误码，按schema兼容情况前向修复。分类和历史号分配不得回滚成已用号码可复用；已移动/删除记录按审计与受控备份处理，不能自动恢复已清理的音频对象。

音频signed URL在过期前可能仍可使用；逻辑删除立即停止签发新播放/上传凭证，但对象回收仍等待已有上传凭证过期。运营告知不得宣称删除瞬间所有已签发链接都被撤回。
