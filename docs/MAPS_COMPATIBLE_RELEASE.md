# 地图兼容发布

本分支 `codex/maps-compatible-release` 从生产 main 分离，仅发布地图和录音地点，不捆绑尚未上线的管理 V2。完整 V2 开发仍保留在 `codex/docs-experience-phase`，不得删除。

## 兼容要求

- 保留原管理端 createBatch、jobs、provision 协议；本分支不引入分类或租约迁移。
- 仅增加 `202610150002_visitor_location.sql`。新的地点 claim RPC 内部调用旧 claim，旧六参数 RPC 继续存在。
- public-tag 仍查询旧 schema，不使用尚不存在的 deleted_at。
- 后台仅增加地点展示和认证查询扩展，不替换为依赖 V2 API 的新管理页面。
- 后续合并完整管理V2时注意迁移编号：生产已有150002但未有150001，需要明确预演和 include-all，不可误认为分类迁移已经应用。

## 当前证据

- 分离后71项前端测试及普通构建通过。数量少于V2开发分支是因为本分支保留旧管理UI测试，不是删除地图测试。
- PGlite 实际执行旧三份迁移和原管理契约，再添加地点迁移，执行地点校验/匿名授权契约，最后重跑原管理契约，通过。验证旧协议在地点迁移后仍可用。
- 原生产录音未改动，生产尚未部署地图功能。

## 发布前剩余
