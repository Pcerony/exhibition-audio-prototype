# 语音转文字：试用接入

## 当前状态（2026-10-17）

负责人已添加 Groq 密钥，集成负责人已启用每分钟一次的转写任务。密钥未写入代码、聊天或文档；尚需用自愿新录音核对实际识别结果。以下配置步骤保留作维护参考，不需要重复创建密钥。

## 这一版做什么

采用 Groq 的 `whisper-large-v3-turbo`。先保存录音，再异步转写，不阻塞录音上传。参观者需要在试听确认页主动勾选同意，默认不选；旧录音不会自动发送给 AI。

文字先作为私有草稿。工作人员在网页后台点击卡片的文字图标，可刷新任务、编辑、保存草稿、发布、隐藏或重新转写。只有发布后的文字才显示在访客收听页的“查看文字”中。原录音始终保留，AI 可能误识别人名、福冈地名、方言或风声。

## 负责人只需要做这一步

1. 登录 [Groq Console](https://console.groq.com/keys)，创建 API Key。先使用可用的免费套餐，不必为本次试验开通付费。
2. 打开现有 Supabase 项目的 **Edge Functions → Secrets**，添加名称 `GROQ_API_KEY`，值为刚创建的密钥，保存。
3. 通知集成负责人“密钥已添加”，无需发送密钥本身。不要把密钥贴进聊天、网页环境变量或 GitHub。

项目仍沿用已有的 Supabase，不需要再买服务器。免费额度和限流以你自己的 Groq 控制台为准；免费服务不是无限量或可用性承诺。

## 集成负责人启用

先确认数据库迁移、四个 Edge Function 与前端已发布，且审核和隐私测试通过。配置脚本只检查密钥名称，不读取或打印密钥，不启用付费，也不轮换现有维护密钥。

```sh
SUPABASE_CLI_BIN=/absolute/path/to/supabase node scripts/configure-transcription.mjs --project-ref ngcvfpyyihhkjqtdvivx --apply
```

密钥未设置时脚本保持转写计划任务停止。设置后复用已有 Vault 维护配置，创建名为 `recording-transcription` 的每分钟任务。每次最多处理一条；这是保守的试用吞吐，不保证提交后立即出字。录音排队期间访客可以正常离开和收听。

```sh
SUPABASE_CLI_BIN=/absolute/path/to/supabase node scripts/verify-transcription.mjs --project-ref ngcvfpyyihhkjqtdvivx --allow-remote-test
```

上述合成验证只创建自有夹具并测试人工文字，不调用 Groq，不代表实际识别质量通过。不得将历史真实录音用作未经同意的测试素材。

## 实际试录验收

用一枚测试空卡，录制约30秒、不含个人隐私的福冈回忆，主动勾选转写并提交。后台刷新文字状态，等待草稿，再听原音逐句核对。至少试日语普通话、福冈地名与少量现场噪声；其他语言另测，不把界面五语等同于识别质量验证。

确认草稿在另一台手机上不可见，发布后才出现，隐藏后消失。转写失败不影响原录音播放；可在后台重试，限频或连续失败时先检查 Groq 控制台，不要反复点击。

重置或删除卡片会取消对应转写；旧任务不能覆盖新录音。重新转写会隐藏旧文字，需要再次确认后发布。永久测试入口 `#/preview` 不上传云端，因此不会生成 AI 文字。

## 运维边界

- 不将 Groq 密钥或 Supabase 服务端密钥交给前端、Android、CSV 或日志。
- 数据库任务使用持久租约，最多三次自动尝试，限流退避；人工编辑/重试使旧工作结果失效。
- 关闭转写可在 Supabase Cron 中停用 `recording-transcription`；不应停用原有音频清理任务。停止定时调度不等于取消已发出的请求。
- Groq 是额外的数据处理服务；正式活动前由负责人确认其隐私政策、数据处理条件、保存期限及公开文字审核安排。
- 现阶段不自动翻译、不概括、不自动公开，也不修改 Android 写卡流程。
