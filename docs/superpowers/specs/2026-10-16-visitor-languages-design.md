# 参观者五语设计

用户已批准增加英语、韩语、繁体中文，与日语和简体中文共五种。日语默认，沿用现有本机语言偏好键，未知值回退日语，不自动覆盖用户选择。

参观者入口、五步流程、地图提示、录音/播放/失败信息、隐私和条款均使用同一词典。语言选择用原生select，显示各语言自称，控制手机占用；切换不丢录音和选点。Google地图按首次初始化语言加载，不因切换重建地图或丢失地点，控件语言下次页面加载生效。

不更改API、音频内容或后台分类；不翻译用户录音。运营界面和Android不在本轮翻译范围，原有中日切换保留。

测试覆盖五语入口、偏好恢复/未知值、无中文泄漏的五步、权限提示、政策与地图语言映射；运行完整前端/后端测试、普通/Pages构建和手机截图后发布。
