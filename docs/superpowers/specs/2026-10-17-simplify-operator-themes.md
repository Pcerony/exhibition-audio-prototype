# 工作人员主题管理简化

负责人确认：参观者四主题选择不等于工作人员手动分类。空卡一律相同；固定A美食/B旅行/C相遇/D其他回忆由参观者选择并在成功提交时自动体现在编号。工作人员无需建立、改名、移动分类。

网页后台和Android管理界面移除分类侧栏/分类筛选/未分类入口与移动分类操作，按录音日期、搜索、录音状态和排序管理；卡号仍保留A/B/C/D，现有主题数据不删除，不改录音、网址、分号或参观者流程。卡片详情可以被动显示既有主题，不能呈现需要人工整理的分类控件。CSV保留原主题元数据用于导出。

不修改数据库契约与已有接口：旧管理客户端可兼容，但新版不再请求分类列表或提交移动操作。Android旧版持久化待处理move不能自动发送，也不得阻塞录音重置/删除和写卡；显示明确历史操作核查/丢弃选项后继续，不偷偷丢弃不确定操作。所有当前重置/删除分组确认、写卡安全队列、转写审核和登录授权保持。

Android版本3.1.1/code7。测试覆盖无分类操作、列表请求无分类过滤、日期仍有效、批量重置删除与旧move恢复保护；全前端/后端、APK/JVM/lint，手机/桌面网页截图。部署网页与分发新APK，不做生产数据迁移，实体NFC/音振仍不能声称真机验收。
