# Android显式覆盖修复

用户要求已有内容芯片可以覆盖，直接更新、不再逐项确认。

根因：`WriterSafety.mayWrite`仅允许空NDEF或唯一相同目标URL；单张“重新写卡”只重新领取租约，没有覆盖许可。

设计：单张选择卡片后提供普通写入和覆盖入口，覆盖需显示目标编号并确认原芯片内容将被替换。覆盖仅授权当前任务/租约的一次物理写入，触碰后消耗，不持久化、不延续到自动模式或下一张卡。直接调用NDEF写入替换完整消息，不先清空；保留云端授权/租约/版本校验、容量/只读检测和物理读回。只读/永久锁定不能绕过。原云端录音和卡片不自动删除。

- [x] 添加失败回归：普通写入拒绝其他内容，显式覆盖允许文本/其他网址/多记录；授权不能跨任务/租约/自动模式。
- [x] 修改纯Kotlin安全规则、NfcWriter和MainActivity，三语确认/错误提示，versionCode 4/versionName 2.1.1。
- [x] 跑26项Android测试/构建/lint，独立审查并修复暂停竞态；检查APK配置/签名，更新中文说明/验证记录。
- [x] 发布v2.1.1-rc1，远端附件大小和SHA256与本地验证产物一致。

自动化不等于实体NFC验收；写入中断不保证芯片内容完整，必须重新读卡确认。实体测试须含外部文本/网址、其他展览编号、多记录、只读和断网/切后台。
