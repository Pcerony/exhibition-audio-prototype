# 项目目标与需求

## 项目

为福冈市展览提供一个声音记忆分享系统。市民无需安装应用或注册，即可通过 NFC 展签录制或收听与福冈市有关的回忆。运营者通过受保护的后台管理展签与录音；工作人员使用 Android 应用批量初始化 NFC 网址。

## 产品规则

- 产品入口是 `https://voice.heisei.space/`。页面支持简体中文和日语，移动端优先，重点验证 iPhone Safari。
- 每枚 NFC 芯片保存一个不同的 NDEF HTTPS URI，URI 指向本系统中的一个展签。芯片保存的是网址，不是音频文件。
- 参观者在首次使用前轻触芯片。网站据 URL token 查询云端展签；未绑定时允许录音、试听、重录、可选昵称，确认后上传；已绑定时只显示音频播放。
- 一枚芯片最多有一段有效录音。只有第一次成功提交能绑定；后续参观者只能听。重置只能由认证运营者执行，重置后可重新录制，NFC 网址保持不变。
- 录音明确告知会向扫描该展签的人公开播放。昵称可选。不要要求访客身份、电话或邮箱。
- Android 写卡工具供工作人员使用，不要求参观者安装。每枚标签从后台取得独立 visitor URL，写入后读回验证。
- 云端音频和标签状态是唯一权威数据；浏览器 localStorage/IndexedDB 只保留为开发演示适配器，不能用于生产或跨设备验收。

## 用户与工作流

### 参观者

1. 用手机轻触展签；手机系统打开芯片内唯一 HTTPS 网址。
2. 网站查询对应标签。未绑定则介绍福冈市记忆主题，用户主动点录音后再申请麦克风权限。
3. 用户试听、必要时重录，可选昵称，明确确认提交。
4. 浏览器先上传候选音频，再请求服务端绑定。提交成功才显示已保存；若并发中另一人先提交，展示已绑定的作品并清理本次候选文件。
5. 后续访客轻触同一标签，播放云端音频。

### 运营者

1. 登录管理后台，创建或 CSV 批量导入展签。
2. 后台生成每枚标签的随机 token 和唯一 visitor URL，并导出写卡清单/待写入批次。
3. 使用 Android 写卡应用逐枚写入 URL、读回验证并回报写卡状态。
4. 在后台搜索、筛选、试听、查看录音状态；只有授权运营者可以重置或停用标签。

## 第一版不做

参观者账号、评论/点赞、自动转写、AI 摘要、离线上传队列、多租户 SaaS、高级分析、多运营者权限层级、把录音写进 NFC 芯片、访客端写卡，以及参观者必须安装 Android/iOS 应用。

## 体验验收

- 标签 A 的 URL 只能查到标签 A；不同标签 URL 不相同且 token 不可预测。
- 在设备 A 录制并提交后，设备 B 打开标签 A 能播放同一段音频；标签 B 不受影响。
- 两台设备同时提交同一未绑定标签，数据库中最终恰有一段有效录音，失败方不覆盖成功方。
- 已绑定页面不显示录音/覆盖入口；只有认证后台可以重置。
- 确认 Safari 权限、iOS 音频格式、屏幕锁定/切换后台、网络中断和重试行为。
- Android 写卡对每枚实际芯片读回 URL，报告 success/failure；同批次可恢复未完成项而不会静默重复标记。
