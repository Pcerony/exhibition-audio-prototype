# 管理手机应用V2：安装与验收

## 本次升级

Android工作人员应用、网页后台与云端分类接口一起升级。新版提供中/日/英三语、记住登录、分类卡片列表与试听、单张写卡、独立自动写卡和批量编辑。默认日语，可在设置中切换中文。

APK是调试签名试用包，不是应用商店正式发行。只支持Android工作人员手机；参观者仍用iPhone/Android浏览器，无需安装。

[下载安卓V2试用包](https://github.com/Pcerony/exhibition-audio-prototype/releases/download/v2.0.0-rc1/voice-writer-v2-candidate.apk)；[网页后台](https://voice.heisei.space/#/admin)。云端V2已上线，旧APK不能继续领取写卡任务。

## 安装前

1. 结束旧版写卡，确认没有待同步结果。本次负责人已确认可以统一升级。
2. 下载本次发布的 `voice-writer-v2-candidate.apk`，在Android允许所用浏览器安装此来源的应用，然后安装。
3. 优先覆盖安装，保留同一签名包的数据。如果系统提示签名冲突，不强行覆盖；先再次确认旧版没有待同步结果，再卸载旧版并安装新版。云端卡片和录音不因卸载而删除。
4. 用已有运营账号登录，不要用Google/Supabase控制台账号代替展览运营账号。首次登录后，应用在设备安全存储中保存加密续期会话，不保存明文密码。

## 四个入口

- 卡片管理：选分类、搜索和筛选，查看录音与写卡状态、提交时间，试听。
- 单张写卡：选定卡片后启动，将芯片靠近手机NFC位置。按提示完成写入及物理读回，不能仅凭“已上传”判断芯片写好。
- 自动写卡：先选一个分类，再点击开始。每张成功后移开芯片，按提示换下一张。普通卡片列表不会自动写入。
- 批量编辑：选择卡片后移动、重置或删除。移动会取得目标分类的新编号，但网址/录音不变；旧编号不复用。删除按空卡与已有录音分开确认；重置保留卡片网址。

顶部设置提供语言、账号/退出登录和NFC设置。失败或断网时看当前提示，不要把未同步项当成云端已完成；不能用跳过冒充写入成功。

## 必须用实体手机确认

1. 登录后关闭并重新打开应用，确认恢复会话；切换三种语言，检查主要页面和错误提示。
2. 用测试分类新建至少两张空卡，单张写一枚芯片，再用另一手机碰它，确认打开的完整网址与后台任务一致。
3. 录一段测试音频，再用另一手机打开并播放，后台也应能试听。
4. 自动模式下保持同一枚芯片不移开，确认不会自动覆盖为下一编号；移开后换另一枚再继续。
5. 检查NFC关闭、断网、切后台、只读/容量不足标签的提示和暂停行为。没有这些标签时标记未测，不猜测通过。
