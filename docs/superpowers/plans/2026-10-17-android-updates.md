# 安卓应用内更新

目标：首次安装 3.3.0 后，打开应用可收到新版提醒，并从设置手动检查更新。无后台常驻推送，不静默安装。

架构：Pages 托管公开版本清单，GitHub Release 托管 APK。独立更新客户端不携带运营账号凭据；校验 HTTPS 来源、大小、SHA256、包名、递增版本和安装签名。FileProvider 仅开放 updates 缓存目录。

- [x] 先写 UpdatePolicy JVM 测试并观察缺失功能导致编译失败，再实现清单解析、下载限制与校验。
- [x] 独立 AppUpdater：检查、下载进度、权限引导和系统安装；界面销毁取消工作，失败不影响写卡。
- [x] 接入启动/设置和三语言文案；写卡、未同步结果存在时不允许进入更新流程。
- [x] 增加清单发布脚本与中文说明；APK 上传后由远端 digest/size 核对生成清单。
- [x] 68 项 Android JVM 单测、构建、lint、签名校验、独立代码审查。审查发现的未登录时持久化待同步保护缺口已补回归测试。
- [ ] 实体手机覆盖安装、首次未知来源授权、更新闭环验收，仍由负责人完成。

候选版：3.3.0 / versionCode 10，Release `v3.3.0-rc1`。APK SHA256：`77b483c365526357819df43946844d888afec6cb75988b7a09c41854dd41ff20`。签名证书 SHA256：`48a52ba6a1cdc413f5ee828b11cd922a4604951299547b7cea37c2e901d04b3d`，与 3.2.0 相同。已扫描全部 DEX，公开 Supabase 配置存在，未发现服务端密钥标记。Lint 为 0 错误；保留系统安装 Intent 的兼容性弃用提示及现有警告。

边界：保持应用数据，不卸载旧版；旧版不具备检查能力，需要最后一次手动安装。Android 要求用户授权此应用安装来源并确认安装。离线或清单故障不阻止现有写卡。
