## 当前开发重点

第一阶段是云端录音闭环：服务端创建标签、参观者上传音频、服务端原子绑定、另一台设备播放。云端后端成为权威数据源后，再接入管理后台和 Android 批量写卡端。路线图中的边界允许不同 Agent 并行，但不得各自定义冲突的 API 或数据状态。

旧的 `docs/superpowers/specs/2026-09-29-exhibition-audio-nfc-design.md` 和早期原型计划记录了单浏览器原型阶段的决定；如与本文档冲突，以本目录核心文档为准。
