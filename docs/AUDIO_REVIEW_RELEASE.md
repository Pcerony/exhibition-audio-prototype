# 管理员录音审核与剪辑

入口：正式网站 `#/admin`，仅 `admin` 角色可见“录音审核与剪辑”。staff/operator没有此权限，服务端亦单独拒绝。

## 工作流

- 选择录音后在浏览器内解码原版、测量实际时长/平均音量并显示波形。可运行全件检查，按日本录音日期和异常候选筛选。
- 拖动波形两端选择保留范围；点击选段内波形定位；可放大选段、回到全局，数值输入用于精调。试听的是本次选段导出的WAV，不依赖有问题的容器时间戳。
- 确认保存后将剪辑设为主音频；原版与剪辑历史保留，支持恢复原版。每次保存最多5分钟，超过范围需缩短选段。
- 切换主版本撤回已公开转写并保留私有草稿，需人工检查后重新发布。之后重试AI转写读取新主版本。
- 异常规则：实际时长<=5秒、>=120秒、与申报时长差异超过max(5秒,20%)、平均音量<=-45dB。不是语音识别或有效性判定，不自动删除。

## 维护

回归命令：`npm test -- --run`、`npm run test:backend`、`npm run test:audio-backend`、`npm run build`、`GITHUB_PAGES=true npm run build`。

部署时先备份/预演数据库，再应用迁移，部署admin-audio/admin-api/public-playback-url/public-tag/staff-api，最后发布Pages。新表RLS开启且只授权service_role。失败上传保留延迟回收项，已保存版本不会被maintenance误删。实际恢复音频不恢复旧公开文字，避免未经复核的文字重新曝光。
